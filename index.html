AGRI-ROVER REQUIRED

TerraGrid's automatic soil-sampling workflow requires an AgriBot rover to collect field measurements. The rover visits generated GPS waypoints, samples soil, and returns results to TerraGrid.

WORKFLOW

How TerraGrid
works.

A simple path from live location to field mission to soil intelligence.

01
Connect ESP32 to Wi-Fi

Connect the AgriBot ESP32 to the same network or access point the browser can reach.

02
Find ESP32 local IP

Read the IP address printed by the ESP32 Serial Monitor.

03
Enter ESP32 endpoint

Enter the mission endpoint, for example http://192.168.1.105/mission.

04
Test connection

Verify that the browser can reach the rover before sending a mission.

05
Map the field

Draw the actual field boundary on satellite imagery.

06
Generate waypoints

TerraGrid adapts the sampling density to the size of the field.

07
Dispatch AgriBot

Send the latitude and longitude waypoints to the ESP32 rover.

08
Read soil results

Load the rover's measurements and inspect every sampling point.
